# Access Control & Physical Security

Practical security training for facility staff — access control, surveillance, and incident reporting.

Security training for facility staff: access control systems, surveillance equipment, threat identification, and emergency procedures. This is hands-on, operational training — how to run the systems day to day, not just design them. You'll cover incident reporting and chain of custody procedures, so security events are documented correctly from the moment they're identified.

## What you'll cover

- Access Control Systems Operation
- Surveillance Systems Basics
- Threat Identification & Response
- Incident Reporting & Chain of Custody

## Who it's for

Security and facilities staff operating access control and surveillance systems.
