# Getting HAZWOPER placements started fast

A checklist for agencies with a site start date coming up.

1. **Confirm the course** with the host: 40-hour, 24-hour or a refresher?
2. **Buy seats in bulk** and enroll workers the same day
3. **Set a finish date**: 40 hours online usually takes a week of steady work
4. **Collect certificates** as each worker finishes
5. **Check refresher dates** for workers already certified ([OSHA 8 Hour HAZWOPER Refresher Training](https://staffing-agencies.hazwoperosha.us/courses/osha-8-hour-hazwoper-refresher-training))
6. **Send the host a roster** with names, course, completion date and certificate copies
7. **Plan the field days**: the host provides supervised field experience on site
