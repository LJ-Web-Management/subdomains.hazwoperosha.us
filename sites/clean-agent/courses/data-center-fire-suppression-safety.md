# Data Center Fire Suppression System Safety Training (Clean Agent Systems)

Clean agent fire suppression safety for occupied data hall environments.

Clean agent fire suppression systems protect data center equipment without the water damage of traditional sprinklers — but they carry their own safety considerations for anyone in the data hall when a system discharges. This course covers clean agent system basics, evacuation procedures, and post-discharge safety. You'll leave able to tell a false alarm from a real discharge event and know exactly what re-entry looks like afterward.

## What you'll cover

- Clean Agent System Basics
- Evacuation Procedures
- Post-Discharge Safety
- Alarm Recognition

## Who it's for

Facilities and fire/life safety staff responsible for data hall fire suppression systems.
