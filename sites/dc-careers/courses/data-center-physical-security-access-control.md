# Data Center Physical Security and Access Control Training

Foundational physical security and access control practices for data hall environments.

A foundational course on data center physical security: badge and access control basics, visitor and vendor escort procedures, and the security posture expected on a data hall floor. Pairs well with the deeper Access Control & Physical Security specialization for staff who operate the systems directly. You'll leave with a clear sense of the common security gaps on a data hall floor and how to report an incident through the right channel.

## What you'll cover

- Access Control Basics
- Visitor & Vendor Escort Procedures
- Physical Security Gaps
- Incident Reporting

## Who it's for

Security and facilities staff responsible for data center floor access.
