# OSHA 8 Hour HAZWOPER (q) Incident Command Training

Incident command for shift supervisors and ERT leaders.

When a release becomes an emergency, someone takes command. This eight-hour course prepares shift supervisors and ERT leaders to set up incident command and run the response.

## What you'll cover

- Incident command system
- Size-up and hazard assessment
- Entry teams and backup
- Safety officer
- Termination and critique

## Who it's for

Shift supervisors, ERT captains and emergency coordinators.
